# 雀魂月卡自动领取

云端自动领取，电脑可以关机。**仅支持 [繁中网页版](https://game.maj-soul.com/1/) 的邮箱＋密码登录**，其他区服和登录方式未适配。

## 第一步：选一种方案，只跟对应教程操作

| | **A：外部定时（推荐）** | **B：GitHub 原生定时** |
|---|---|---|
| 谁来触发 | cron-job.org | GitHub 自己 |
| 配置难度 | 多注册一个账号、创建令牌 | 配置较少 |
| 触发时间 | 默认北京时间每天 09:30 | 每天 09:30、15:30 |
| 注意 | 令牌到期需更换；仍依赖 Actions 执行 | **可能延迟或漏跑；没触发就可能没邮件** |
| **开始配置** | **[👉 A 方案教程](docs/EXTERNAL-SCHEDULER.md)** | **[👉 B 方案教程](docs/NATIVE-SCHEDULER.md)** |

**不知道选哪个？选 A。** 本仓库遇到过“手动成功、原生定时不触发”，外部触发测试已通过。两种方案均不保证绝不漏跑。

> 选择 A 不需要开启 GitHub 原生定时变量。教程会说明如何暂停已有的 B 配置；不要把 GitHub 工作流整体禁用，否则 A 也不能运行。

## 第二步：开启邮件通知

完成 A 或 B 后，按 **[手机邮件通知设置](docs/NOTIFICATIONS.md)** 操作。可以收进个人邮箱，保留教育邮箱。

邮件报告工作流成功或失败，具体领取结果看 Summary。**通知不等于独立漏跑报警**，任务根本没启动时可能没有邮件。
